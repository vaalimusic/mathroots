## 🌟 Ключевые возможности

### 1. Интерактивная карта знаний и семантический зум
* **Иерархия слоёв (Layer 0–4)**: наглядный путь от фундаментальных аксиом (числа, операция сложения) через законы равенства до целевого решения задачи.
* **Физические чашечные весы**: сохранение баланса равенства при вычитании, сложении, умножении и делении.
* **Мосты понятий (Bridges)**: демонстрация глубинных связей (например, умножение как повторяющееся сложение).

### 2. Двухуровневый искусственный интеллект (AI)
* **🌟 Серверный AI по умолчанию**: платформа работает сразу «из коробки» абсолютно бесплатно для всех посетителей. Не требует ввода ключей и регистрации у провайдеров.
* **⚡ Персональные настройки (BYOK — Bring Your Own Key)**: любой пользователь может подключить свой собственный API-ключ (**OpenRouter**, **DeepSeek Reasoner/Chat**, **Google Gemini**, **OpenAI**, **ЯндексGPT**) или указать корпоративный Proxy / зеркало. Ключ хранится исключительно локально в браузере.
* **Многоуровневый наставник («Почему я могу это сделать?»)**:
  * **Ребёнок (10 лет)** — наглядные аналогии (коробки, яблоки, весы).
  * **Школа** — понятные стандартные правила алгебры.
  * **Университет** — формальная аксиоматика Пеано, свойства колец и полей.
  * **Программист** — через чистые функции, типы данных, циклы и инварианты AST.

### 3. Визуальная лаборатория (9 интерактивных симуляций)
1. **Чашечные весы** — интерактивное решение линейных уравнений с анимацией равновесия.
2. **Парабола и корни** — коэффициенты $a, b, c$, дискриминант $D$ и геометрический смысл корней.
3. **Тригонометрический круг** — единичная окружность, синус, косинус, тангенс и радианы.
4. **Теорема Пифагора** — физическое равенство площадей $a^2 + b^2 = c^2$.
5. **Касательная и производная** — мгновенная скорость изменения и предел секущей.
6. **Дробные полосы** — наглядное сложение и приведение дробей к общему знаменателю.
7. **Степени и логарифмы** — обратимость показательной и логарифмической функций.
8. **Системы уравнений** — точка пересечения прямых на плоскости.
9. **Векторы** — сложение по правилу параллелограмма и проекции.

### 4. Конструктор задач (AI Decomposer & Tree Builder)
* Автоматическая декомпозиция любого введённого уравнения в граф зависимостей.
* Ручное добавление узлов, редактирование формул в KaTeX и проверка шагов.
* Генерация публичных ссылок (`?shared=<slug>`) для отправки ученикам.

### 5. Конспекты A4 & Шпаргалки
* Готовые конспекты по темам с математической разметкой KaTeX.
* Печать конспектов на листах формата A4 без водяных знаков.

## 🚀 Быстрый старт в Docker

Проект полностью оптимизирован для контейнеризации с использованием **Docker Compose** и легковесного образа **Node.js Alpine**:

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/YOUR_USERNAME/matematika.git
cd matematika

# 2. Запустите стек сервисов (Frontend + Express API + PostgreSQL 16)
docker compose up -d --build

# 3. Проверьте статус контейнеров
docker compose ps
```

Приложение станет доступно по адресу: **`http://localhost:3000`**.

## 🔐 Первоначальная настройка администратора

В проекте **отсутствуют захардкоженные пароли** для обеспечения максимальной безопасности при публичной публикации.

1. Откройте в браузере секретный URL входа:
   ```text
   http://localhost:3000/vaalimusic
   ```
   *(или `https://ваш-домен.ru/vaalimusic`)*
2. При первом посещении система автоматически определит, что администратор ещё не настроен, и откроет **Мастер первоначальной настройки**:
   * Введите логин администратора (по умолчанию `admin`).
   * Введите и подтвердите ваш мастер-пароль (не менее 6 символов).
3. Нажмите **«Создать администратора и войти»**.
4. В открывшейся панели управления вы сможете:
   * Настроить центральный AI-провайдер платформы (OpenRouter, DeepSeek, Gemini, OpenAI, YandexGPT).
   * Задать системный API-ключ и прокси.
   * Просмотреть статистику умного кэша токенов и управлять платформой.

## 💻 Локальная разработка без Docker

Если вы хотите запускать проект локально в режиме быстрой разработки с Hot-Reload (Vite):

```bash
# 1. Установите зависимости
npm install

# 2. Скопируйте конфигурацию окружения
cp .env.example .env

# 3. Запустите локальный сервер разработки
npm run dev
```

Приложение запустится на `http://localhost:3000`. Если PostgreSQL не запущен локально, сервер автоматически активирует встроенное отказоустойчивое in-memory хранилище.

## 🐙 Как опубликовать на GitHub

Для публикации репозитория на GitHub (в публичный доступ):

```bash
# 1. Создайте новый публичный репозиторий на GitHub (например, matematika)
# Внимание: не ставьте галочки "Add README", "Add .gitignore"

# 2. Добавьте адрес вашего удалённого репозитория
git remote add origin https://github.com/YOUR_USERNAME/matematika.git

# 3. Убедитесь, что основная ветка называется master (или main)
git branch -M master

# 4. Отправьте код в GitHub
git push -u origin master
```

> **Безопасность проверена:**  
> Все персональные ключи, токены и пароли удалены из файлов проекта и истории коммитов. Конфигурационные файлы `.env` включены в `.gitignore`.

## 🌐 Настройка Production-домена (math.everty.ru)

### Nginx Reverse Proxy конфигурация с SSL

```nginx
server {
    listen 80;
    server_name math.everty.ru;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name math.everty.ru;

    ssl_certificate /etc/letsencrypt/live/math.everty.ru/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/math.everty.ru/privkey.pem;

    # Рекомендуемые параметры безопасности
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```
