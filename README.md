# 🧠 MathRoots — Интерактивная карта корней математики

> **«Любая сложная задача имеет корни»** — интерактивная платформа для глубокого понимания математики через визуальные модели, семантический зум, механику «Почему?», отладчик когнитивных затыков и древовидную декомпозицию задач.

---

## 🌟 Ключевые возможности

1. **Интерактивный холст и семантический зум**:
   * Наглядная навигация от корневых аксиом (Layer 0) к промежуточным законам и целевому решению (Layer 4).
   * Поддержка альтернативных ветвей решений (дискриминант, факторизация, геометрический метод).
2. **Механика «Почему я могу это сделать?»**:
   * 4 уровня объяснения под каждого пользователя: **Новичок (10 лет)**, **Школа**, **Университет (аксиоматика)** и **Для программиста** (чистые функции, инварианты).
   * Голосовая озвучка математики на русском языке (`Web Speech API`).
3. **Визуальная лаборатория (9 интерактивных симуляторов)**:
   * Интерактивные чашечные весы (`2x + 4 = 10`), парабола и корни, тригонометрический круг, геометрическая модель Пифагора, касательная к графику функции, дробные полосы и степени/логарифмы.
4. **Отладчик когнитивных пробелов (Deep Gap Finder & Stuck Debugger)**:
   * Диагностика первопричины ошибки вниз по графу понятий и генерация точечного микро-упражнения.
5. **Тренажер (100+ задач с ловушками)**:
   * Разбор типичных ошибок (например, неявное умножение `2(3)`), подсчет XP, серий побед и фиксация прогресса в базе данных.
6. **Конструктор задач (Tree Builder)**:
   * Декомпозиция произвольного уравнения или текстовой задачи в иерархический граф.
   * Генерация публичной ссылки (`?shared=<slug>`) для отправки ученикам или одноклассникам.

## 🏗️ Архитектура продакшна

* **Frontend**: React 19, TypeScript, Tailwind CSS v4, Motion, Lucide Icons, KaTeX.
* **Backend**: Node.js 22, Express, Helmet, CORS, Compression, Rate Limiter.
* **Database**: PostgreSQL 16 (с автоматической миграцией схемы и resilient in-memory fallback для локальной разработки без БД).
* **Контейнеризация**: Multi-stage `Dockerfile` (минимальный образ на Alpine, запуск от непривилегированного пользователя `appuser`) и `docker-compose.yml`.

## 🚀 Запуск и Развертывание

### Вариант 1: Запуск в Docker Compose (Рекомендуемый для продакшна)

1. Убедитесь, что запущен **Docker**:
   ```bash
   docker compose up -d --build
   ```
2. Откройте в браузере: **`http://localhost:3000`**
3. Посмотреть статус контейнеров и логи:
   ```bash
   docker compose ps
   docker compose logs -f app
   ```
4. Остановить сервисы:
   ```bash
   docker compose down
   ```

### Вариант 2: Локальный запуск без Docker

1. **Установка зависимостей**:
   ```bash
   npm install
   ```

2. **Настройка окружения** (опционально):
   Скопируйте `.env.example` в `.env` и при необходимости укажите ваш ключ Gemini или параметры PostgreSQL:
   ```env
   PORT=3000
   DATABASE_URL="postgresql://postgres:mathroots_secure_pass_2026@localhost:5432/mathroots?sslmode=disable"
   GEMINI_API_KEY="ваш_ключ"
   ```
   *(Если PostgreSQL не запущен, сервер автоматически запустится во встроенном отказоустойчивом режиме хранилища)*.

3. **Запуск в режиме разработки**:
   ```bash
   npm run dev
   ```

4. **Сборка и продакшн-запуск**:
   ```bash
   npm run build
   npm start
   ```

## ⌨️ Горячие клавиши (Hotkeys)

* **`Ctrl + K`** — Быстрый фокус на поиск уравнений и задач
* **`Ctrl + N`** — Онбординг / выбор новой задачи
* **`Ctrl + B`** — Открыть Конструктор задач (Tree Builder)
* **`Esc`** — Закрыть модальные окна и вернуться на холст
